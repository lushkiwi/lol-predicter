# Player-targeting features

Generated by `python -m draft_analyzer.experiments player report`. Validation split only (651 games / 240 series, 13015 actions); the test split is not touched. Every model is the M3 recipe (all games, 365-day decay) fitted with the same seed for negative sampling and LightGBM; `diff` is model minus `base`, paired bootstrap by series, 95% CI.

- **base**: the features of the M3 model.
- **target**: base + bans aimed at a player (player_banned_vs_own, player_ban_focus_own, player_banned_vs_opp, player_ban_focus_opp).
- **pinch**: base + the player's remaining pool (player_pool_share_left_own, player_pool_frac_left_own, player_pool_n_left_own, player_pool_share_left_opp, player_pool_frac_left_opp, player_pool_n_left_opp).
- **both**: all of them.
