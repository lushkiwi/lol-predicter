Font options for Draft Predictor

Each card sets the same pieces of the page in a different pair of typefaces: a condensed one for names, headings and big numbers, and a plain one for everything else.

The first card is what the site uses today: fonts already on the computer, so it looks like this on a Mac and plainer on Windows and Android. The others are free web fonts that would look the same everywhere. This preview loads them from Google Fonts; the site itself would carry its own copies. A card whose font did not load says so in its top right corner.
